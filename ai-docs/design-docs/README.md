## 当前共识

1. 插件打开后直接进入快捷键列表，不增加中间首页。
2. 快捷键以方块按钮展示：上方为图标，下方为两行文字；第一行为大号中文动作名称，第二行为小号灰色快捷键组合。
3. 普通模式点击方块后立即发送固定快捷键，并显示按下反馈。
4. 编辑模式允许拖拽调整方块顺序和位置。
5. 快捷键组合、图标和快捷键定义由插件固定，用户不能修改或新增快捷键。
6. 用户可以选择每行 3、4 或 5 列。
7. 方块始终保持正方形，网格自动适配屏幕宽度；左右边距与方块之间的间距保持一致。
8. 内容超过屏幕高度时使用纵向滚动。
